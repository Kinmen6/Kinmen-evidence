# KM 乐透 · 公开存证仓库

本仓库存放 KM 乐透每期开奖的**固定存证材料**（GitHub 提交 + OTS 时间戳），供公众独立核验。

## 怎么看

- **全量索引**：[EVIDENCE-INDEX.json](EVIDENCE-INDEX.json) — 每一期、每个阶段（开奖前承诺 / 开奖后完整材料）的**固定提交直达链接**
- 每期文件位置：`records/YYYY-NNN-precommit.json`（开奖前承诺）、`records/YYYY-NNN-revealed.json`（开奖后完整材料）
- 每个文件对应一个**固定 commit**（不可变），链接指向具体 commit 而非可变动分支

## 核验方法

1. 在索引中找到期号 → 打开固定链接查看文件内容
2. 对照官网公开的承诺哈希 / 开奖号码核验
3. OTS 时间戳凭证与状态见官网存证记录（正式期次自动盖章）

> 历史期次（2020-01-01 起）为部署补传材料，GitHub 提交时间可核验；OTS 自正式期次起自动存证。
